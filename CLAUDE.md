# ControlLeads

Lead management system (CRM/funnel) for **international student recruitment**. Single institution (single-tenant). **Entire product in English** (UI, enums, API, code); project docs in Portuguese.

## Monorepo layout

```
backend/   Spring Boot (Java) + PostgreSQL — single source of business logic
web/       Angular (signals) + ECharts — animated dashboards        [not scaffolded yet]
app/       Flutter (Android + iOS) — same APIs as web               [not scaffolded yet]
shared/
  api-contract/    openapi.yaml exported from springdoc → generates TS + Dart clients
  design-tokens/   tokens.json (Style Dictionary) → CSS vars (web) + ThemeData (app)
.spec/     SDD discovery & specs — READ THIS FIRST
```

## Where the truth lives

- **`.spec/discovery/`** — approved product discovery: `brief.md`, one `module_*.md` per module (RFs/RNs), `entities.md` (data model), `roadmap.md` (execution order, 15 suggested SPECs).
- **`.spec/memory/`** — structural decisions (overview, phases, stack).
- **`backend/src/main/resources/db/migration/V1__initial_schema.sql`** — initial schema, already written from entities.md. Treat as the data-model reference.
- **`shared/design-tokens/tokens.json`** — visual source of truth incl. per-status colors.

## Core domain rules (do not violate)

1. **Funnel**: `LEAD → HOT_LEAD → APPLICATION → STUDENT` + `STALLED` (paused, records `stalled_from_status` + `stall_reason`). STALLED reactivates back to the stage it left. STUDENT is terminal (admin-only correction).
2. **Every status change writes an immutable `lead_status_events` row** — ALL funnel/drop-off/conversion reports derive from events, never from current status.
3. **Ownership visibility**: `MARKETING_TEAM` users see/edit only leads where `assigned_to = them`; `ADMINISTRATOR` sees all. Enforced in the backend on every endpoint, never only in UI.
4. **Aggregations happen only in the backend** — web and app must show identical numbers.
5. Catalogs (`courses`, `channels`, `stall_reasons`) and `users` are **deactivated, never deleted** (history references them).
6. Contact activities (`CALL`, `EMAIL`, `WHATSAPP`, `MEETING`) update `leads.last_contacted_at` — the SLA clock. SLA applies to HOT_LEAD only; max 1 alert per lead per cycle.

## Architecture decisions (settled — don't relitigate)

- UUIDs generated by the application; optimistic locking (`version`) on `leads`.
- Auth: JWT access + rotating refresh; roles `ADMINISTRATOR` | `MARKETING_TEAM`.
- Contract-first between clients: springdoc exports OpenAPI → generated typed clients (TS for Angular, Dart for Flutter). Never hand-write API models in clients.
- Errors: RFC 7807 ProblemDetails end-to-end.
- Charts: ECharts (web), fl_chart (app, map spike pending — fallback: bar ranking by country).
- Duplicate lead (same email/phone): **warn, don't block**.
